# BaseBuilder sprite set

Clean transparent isometric Mars colony assets for the inside-base scene.

Folder target:
`Assets/sprites/BaseBuilder/`

The individual PNGs were isolated from the generated atlas so neighboring sprites and stray fragments are removed.

Key assets:
- `command_center.png`
- `habitat_dome_small.png`
- `habitat_dome_large.png`
- `greenhouse_complex.png`
- `solar_power_station.png`
- `water_processing_complex.png`
- `industrial_refinery.png`
- `satellite_comms_center.png`
- `rover_garage.png`
- `storage_warehouse.png`
- `landing_pad.png`
- `base_gate.png`
- walls, roads, build pads, planters, rover, astronaut, drone and cargo props
